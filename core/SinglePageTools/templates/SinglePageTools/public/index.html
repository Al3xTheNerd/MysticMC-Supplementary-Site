Single Page Tools

  • These tools are just some small single page tools made to help you with various things from item management, to job planning.

Jobs Pay Calculator

  • This calculator lets you see many things relating to jobs, ranging from how many actions you need to get to a goal level, to just the simple things like how much xp or cash do you get per action at any given level.

Block Break Speed Calculator

  • This calculator checks how fast you can break a block, based on which custom itme you're using and what extra effects you have.

Item Tracker

  • This tool will give you a list of every item on the server, and you can use this to check off which items you already have, at the bottom of the screen it will give you a list of missing items that you can copy/paste directly into Discord for a nicely formatted list.

Misc. Item Tracker

  • This tool will give you a list of every miscellaneous item on the server, and you can use this to check off which items you already have, at the bottom of the screen it will give you a list of missing items that you can copy/paste directly into Discord for a nicely formatted list.

Inventory Planner

  • You can use this tool to plan out which items you would like to use in your inventory, then copy the code to share with others and show off you're beautiful loadout.

Gradient Maker

  • This tool helps you generate a simple gradient to use for prefixes, rename, or nicknames!

Gambling

  • Are you perhaps a broke, penniless individual but want to gamble anyways? Use this page to live out your wildest dreams and gamble 1k keys at a time, you're still gonna pull all 4% items anyways!
